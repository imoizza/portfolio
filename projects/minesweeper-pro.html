Minesweeper PRO

An advanced JavaFX take on Minesweeper with a glassmorphism interface and two mechanics of my own: a shield you keep between games, and a time bonus for playing fast.

01 · Overview

Classic rules, a modern shell

Minesweeper PRO keeps the original game intact and wraps it in a responsive blue glassmorphism UI: a setup screen for difficulty and time limit, a real-time HUD, and custom modal dialogs in place of the default JavaFX alerts. Two mechanics change how it actually plays.

Setup

One screen picks difficulty (Easy, Medium, Hard) and a time limit (1, 2 or 5 minutes) through toggle buttons. Difficulty sets the grid size, the mine count (4, 20, 40) and the timer together.

02 · Persistent shield

A shield you keep between games

Every game hides one shield in a random safe cell. Open that cell and it goes into a permanent inventory, stored with Java Preferences so it survives closing the app.

Click a mine while holding a shield and a dialog offers one last save. Use it and the mine is defused, the cell reveals as safe, the shield and mine counters both drop by one, and the progress bar updates so play continues. Decline and it is game over.

The win check accounts for this: a board is won when every safe cell is open and every mine is either flagged or defused.

03 · Dynamic time bonus

Twenty seconds for playing fast

Clear half of the safe cells within the first quarter of your time limit and the game adds 20 seconds. A dialog confirms it, and the timer jumps the moment you close it: a 60 second game becomes 80.

04 · The screens

Every state has a look

Difficulty scales the whole board.

In game

The HUD carries the countdown, a win progress bar, the shield inventory, the remaining mine count and a quit button. Reveals cascade recursively through empty regions.

Endings

Win, loss and time out each get their own top-to-bottom animation: confetti for a win, sad emojis for a loss (with every mine revealed), and a Time's Up screen when the clock runs out. Each offers Home and Retry.

05 · Under the hood

How it runs

GameSetupController loads the settings screen. Start Game hands off to GameController, which builds the grid, places the mines and the shield, loads the saved shield count and starts the countdown. All the game logic lives in that one controller: recursive reveals, mine handling, and the shield and bonus rules. It launches the same way as the practical exercises from class.

  • Java Preferences for shield persistence across sessions.
  • Recursive flood reveal for empty regions.
  • Custom modal overlays replacing JavaFX alerts, with enter and exit animations.
  • Responsive layout that adapts grid, mines and timer to the chosen difficulty.
